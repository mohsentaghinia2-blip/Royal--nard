# تخته‌نرد سلطنتی — نسخهٔ آزمایشی ۱۰٫۰

این بسته شامل نسخهٔ تمام‌صفحهٔ بازی و فایل‌های پایهٔ PWA است.

## فایل‌ها
- `index.html`: رابط و منطق بازی
- `manifest.webmanifest`: تنظیمات نصب وب‌اپ
- `sw.js`: کش پوستهٔ برنامه و پشتیبانی از اجرای آفلاین
- `icon-192.png` و `icon-512.png`: آیکن‌های نصب؛ باید از مخزن قبلی کپی شوند.

## نصب در GitHub Pages
1. از مخزن فعلی یک نسخهٔ پشتیبان بگیرید.
2. فایل‌های `index.html`، `manifest.webmanifest` و `sw.js` را با فایل‌های همین بسته جایگزین کنید.
3. آیکن‌های فعلی `icon-192.png` و `icon-512.png` را در ریشهٔ مخزن نگه دارید.
4. منتظر بمانید GitHub Pages به‌روزرسانی شود، سپس آدرس سایت را باز کنید.
5. اگر نسخهٔ قبلی همچنان دیده شد، داده‌های سایت را در مرورگر پاک کنید یا یک‌بار در حالت ناشناس باز کنید؛ سرویس‌ورکر جدید نام کش جداگانه دارد.

## کنترل کیفیت و محدودیت‌ها
این نسخه برای آزمون عملی است و نباید بدون تست مستقل، نسخهٔ تجاری تلقی شود. منطق حرکت شامل جلوگیری از ورود به خانهٔ بسته، اجبار ورود از بار، بیشینه‌سازی تعداد تاس‌های مصرف‌شده، اولویت تاس بزرگ‌تر در حالت مصرف تنها یک تاس، زدن تک‌مهره و خروج مهره‌هاست. هوش مصنوعی ساده است. قبل از انتشار، باید بازی‌های کامل و سناریوهای خاص قوانین تخته‌نرد توسط بازیکن خبره و روی دستگاه‌های واقعی آزمایش شوند.

## نکتهٔ آیکن
فایل‌های PNG آیکن از تصاویر ارسالی بازسازی نشده‌اند؛ آیکن‌های فعلی مخزن را نگه دارید و همراه این سه فایل منتشر کنید.
