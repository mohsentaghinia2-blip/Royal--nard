# تخته‌نرد سلطنتی — بستهٔ وب‌اپ اندروید (نسخهٔ ۱۰٫۶٫۲)

این بسته بر پایهٔ آخرین سورس بازیِ بازیابی‌شده، نسخهٔ ۱۰٫۶٫۱، آماده شده است. رابط چوب گردو و قاب طلایی سلطنتی حفظ شده و Manifest و Service Worker برای استقرار در زیرمسیر GitHub Pages بازبینی و تکمیل شده‌اند.

## فایل‌های ریشه
- `index.html` — رابط بازی، تخته، تاس، امتیاز و منطق فعلی بازی
- `manifest.webmanifest` — نام، توضیحات، آیکون‌ها و تنظیمات نصب PWA
- `sw.js` — کش پوسته و پشتیبانی آفلاین؛ نام کش نسخهٔ جدید است و کش‌های قدیمی Royal Nard را پاک می‌کند
- `icon-192.png` و `icon-512.png` — آیکون‌های نصب

## استقرار روی GitHub Pages
۱. از مخزن فعلی یک نسخهٔ پشتیبان بگیرید.
۲. پنج فایل بالا را مستقیماً در ریشهٔ مخزن `Royal--nard` جایگزین کنید؛ پوشهٔ حاوی فایل‌ها را به‌جای خود فایل‌ها آپلود نکنید.
۳. Commit changes را انجام دهید.
۴. پس از پایان انتشار GitHub Pages، این نشانی‌ها باید در مرورگر باز شوند:
   - `https://mohsentaghinia2-blip.github.io/Royal--nard/`
   - `https://mohsentaghinia2-blip.github.io/Royal--nard/manifest.webmanifest`
   - `https://mohsentaghinia2-blip.github.io/Royal--nard/sw.js`
۵. اگر نسخهٔ قدیمی دیده شد، صفحه را کامل ببندید و در حالت ناشناس باز کنید؛ در صورت نیاز داده‌های سایت و Service Worker قدیمی را از تنظیمات مرورگر پاک کنید.

## وضعیت اعتبارسنجی این بسته
- JSON مانیفست با parser بررسی شده است.
- JavaScript صفحه و Service Worker از نظر نحوی بررسی شده‌اند.
- ابعاد PNGها بررسی شده‌اند: ۱۹۲×۱۹۲ و ۵۱۲×۵۱۲.
- ZIP از نظر ساختار و سلامت آرشیو بررسی شده است.
- آزمون‌های دود (smoke tests) منطق قواعد شامل ۱۵ مهرهٔ آغازین هر طرف، ورود از بار، خانهٔ بسته، زدن تک‌مهره، خروج دقیق و خروج با تاس بزرگ‌تر، بیشینه‌سازی تعداد تاس‌های قابل بازی اجرا شده‌اند.

## محدودیت‌های انتشار
این بسته **APK یا AAB امضاشده نیست**. برای ساخت فایل نصب اندروید باید فرایند بسته‌بندی Android و امضای خروجی انجام شود. در این محیط Android SDK و کلید امضای خصوصی کاربر در دسترس نیست؛ بنابراین APK ساخته‌شده یا امضاشده ادعا نمی‌شود.

منطق فعلی حرکت چند قانون پایه و مهم را پیاده‌سازی می‌کند، اما این آزمون‌های دود جایگزین آزمون کامل بازی‌های واقعی، تمام وضعیت‌های استثنایی و داوری یک بازیکن باتجربه نیستند. هوش مصنوعی فعلی ساده است و برای محصول تجاری باید ارتقا و ارزیابی شود.

## ساخت اندروید
پس از انتشار موفق PWA، می‌توان از PWABuilder یا Bubblewrap برای ساخت بستهٔ Android استفاده کرد. برای نصب مستقیم روی گوشی، APK امضاشده لازم است؛ برای انتشار در Google Play، AAB امضاشده لازم است. کلید امضا باید نزد مالک پروژه نگهداری و پشتیبان‌گیری شود.
