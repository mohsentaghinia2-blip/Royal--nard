# تخته‌نرد سلطنتی — نسخه آزمایشی 5.0

## تغییرات این مرحله
- امتیازدهی پایه‌ی مسابقه: برد معمولی ۱، گامون ۲ و بک‌گامون ۳ امتیاز
- ذخیره‌ی امتیاز مسابقه و هدف مسابقه در localStorage مرورگر
- هدف مسابقه قابل تنظیم بین ۱ تا ۱۵
- تم چوب گردو و طلایی، حالت دونفره و حریف رایانه‌ای، فایل‌های PWA

## اجرا و نصب وب‌اپ
1. ZIP را استخراج کنید.
2. `index.html` را برای آزمایش باز کنید.
3. برای نصب وب‌اپ و آفلاین‌شدن مطمئن، فایل‌ها را روی HTTPS میزبانی کنید و در مرورگر «Install app» یا «Add to Home screen» را انتخاب کنید.

## محدودیت مهم
این پروژه هنوز APK/AAB امضاشده و آماده‌ی انتشار تجاری نیست. پیاده‌سازی قواعد و امتیازدهی نیازمند تست مستقل و کامل است؛ به‌ویژه تشخیص دقیق بک‌گامون، حرکت اجباری، استفاده از بیشترین تاس و حالات خاص خارج کردن مهره‌ها. هوش مصنوعی نیز هنوز ساده است. قبل از فروش، باید مجموعه آزمون‌های قوانین، ذخیره‌سازی و عملکرد روی دستگاه‌های مختلف اجرا شود.


## آماده‌سازی برای میزبانی از گوشی
این بسته آیکن‌های PWA با اندازه‌های 192 و 512 پیکسل را نیز دارد. برای نصب وب‌اپ، فایل‌ها باید روی HTTPS میزبانی شوند؛ باز کردن مستقیم `index.html` به‌تنهایی نصب PWA یا service worker را فعال نمی‌کند.
برای ساخت APK از مسیر گوشی‌محور می‌توان فایل‌ها را در یک مخزن عمومی GitHub قرار داد، GitHub Pages را فعال کرد و URL سایت را در PWABuilder وارد کرد. قبل از انتشار، قوانین بازی و هوش مصنوعی باید کامل تست شوند.
